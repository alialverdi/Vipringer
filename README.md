# زنگ مخاطبین ویژه (VipRinger)

وقتی گوشی روی **سایلنت**، **ویبره** یا **مزاحم نشوید** است، تماس مخاطبینی که انتخاب کرده‌اید با صدای کامل زنگ می‌خورد.

## ساخت در Android Studio
1. پوشه‌ی `VipRinger` را با File → Open باز کنید و صبر کنید Gradle Sync تمام شود.
2. Run ▶ (یا Build → Build APK(s)).
   - AGP 8.7.3، Kotlin 2.0.21، Gradle 8.11.1، حداقل اندروید ۶ (API 23). هیچ کتابخانه‌ی جانبی ندارد.

## اولین اجرا روی گوشی
1. همه‌ی دسترسی‌ها را بدهید (مخاطبین، تلفن، **گزارش تماس** — بدون این آخری شماره‌ی تماس‌گیرنده دیده نمی‌شود).
2. «دسترسی مزاحم نشوید» را برای برنامه روشن کنید.
3. «خارج کردن از بهینه‌سازی باتری» را بزنید.
4. در سامسونگ: Settings → Battery → Background usage limits → برنامه را به **Never sleeping apps** اضافه کنید.
5. «+ افزودن» → مخاطبین را تیک بزنید → ذخیره.
6. دکمه‌ی «آزمایش زنگ» را با گوشی سایلنت امتحان کنید.

## نحوه‌ی کار
- هنگام زنگ خوردن، شماره با فهرست ویژه مقایسه می‌شود (۱۰ رقم آخر؛ پس 0912… و ‎+98912… یکی‌اند).
- اگر گوشی بی‌صدا باشد، آهنگ زنگ پیش‌فرض گوشی روی کانال «زنگ هشدار» پخش می‌شود (این کانال با سایلنت قطع نمی‌شود) + لرزش.
- با جواب دادن، رد کردن یا دکمه‌ی «قطع صدا» در اعلان، صدا قطع و بلندی صدای هشدار و حالت مزاحم نشوید به حالت قبل برمی‌گردد.

## فایل‌ها
- `CallReceiver.kt` — تشخیص تماس ورودی
- `RingController.kt` — پخش زنگ، لرزش، اعلان و برگرداندن تنظیمات
- `VipStore.kt` — ذخیره‌ی مخاطبین و تنظیمات
- `MainActivity.kt` / `ContactPickerActivity.kt` — صفحه‌ها
